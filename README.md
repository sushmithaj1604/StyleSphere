# Style Atelier — Fashion Design Website

A responsive, multi-page fashion inspiration website made with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract `style-atelier-20-pages.zip`.
2. Open the `styleatelier` folder in VS Code.
3. Open `index.html` in your browser, or install the Live Server extension and click **Go Live**.
4. Images load from Unsplash, so internet access is needed for the fashion photos.

The previous `collections.html` and `lookbook.html` addresses redirect to their combined pages.

## Interactive features
- Responsive mobile navigation
- Trend and designer-look category filters
- Search through looks
- Save looks and customized outfits to a Saved page using browser storage
- Outfit, accessories, shoes, and finishing-touch choices in the Styling Studio
- Contact and newsletter demo forms with confirmation message

This is a front-end project. Contact/newsletter forms do not send data to a server until you connect a backend.
